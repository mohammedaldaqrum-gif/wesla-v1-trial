# إصلاح تشغيل Windows — وِصلة جملة V1.0.1

## بنية المشروع
يحتوي المشروع على:
- `backend/server.js`
- `frontend/index.html`
- مشغلات BAT في جذر المشروع.
قد تفشل المشغلات القديمة إذا نُقلت إلى مجلد آخر أو شُغلت من داخل ZIP. استخدم المشغلات الموجودة في جذر النسخة الحالية.

## التشغيل
1. فك ضغط الحزمة كاملة إلى مجلد عادي قابل للكتابة.
2. ثبّت Node.js 22.13 أو أحدث.
3. شغّل `Run-WESLA.bat` للكمبيوتر نفسه، أو `Run-WESLA-LAN.bat` لاختبار الهواتف على شبكة موثوقة واحدة.
4. اترك النافذة مفتوحة واستخدم العنوان الفعلي الذي يطبعه الخادم.
5. لا تفتح `server.js` بالنقر المزدوج ولا تلصق محتوياته في CMD.

## إذا لم يبدأ
شغّل `Diagnose-WESLA.bat` وأرسل محتوى `WESLA_Diagnostics.txt` بعد إزالة أي بيانات خاصة. لا ترسل قاعدة البيانات أو صور جوازات السفر أو الإيصالات.

## النسخ والاستعادة
تُنشأ نسخ احتياطية متسقة باستخدام `VACUUM INTO`. قبل الاستعادة، أوقف الخادم ثم شغّل `Restore-Backup.bat` وأدخل مسار ملف النسخة الاحتياطية.

## تحذير
النسخة نموذج أولي للاختبار. استخدم بيانات وهمية إلى حين اكتمال المراجعة الأمنية والمحاسبية والقانونية.
