# وِصلة جملة — WESLA WHOLESALE V1.0.1

منصة تجريبية عربية RTL لتنسيق طلبات الجملة والتوصيل والفواتير والديون والخزينة ومتابعة العهد.

> **حالة النسخة:** نموذج أولي متقدم للاختبار المحلي والشبكي الموثوق، وليس معتمدًا بعد للإنتاج المالي أو للنشر العام على الإنترنت.

## التشغيل على Windows

### المتطلبات
- Windows 10/11
- Node.js 22.13 أو أحدث (يتضمن `node:sqlite`)
- فك ضغط المشروع كاملًا في مجلد عادي قابل للكتابة

### تشغيل محلي على الكمبيوتر نفسه
1. فك ضغط الحزمة.
2. افتح المجلد `WESLA_V1_0_1`.
3. اضغط مرتين على `Run-WESLA.bat`.
4. اترك نافذة التشغيل مفتوحة، وافتح العنوان الذي يطبعه الخادم.
5. عند أول تشغيل، يطبع الخادم كلمة مرور مؤقتة للمالك. غيّرها فورًا.

### تشغيل على عدة هواتف عبر Wi-Fi
1. صِل الكمبيوتر والهواتف بشبكة Wi-Fi موثوقة واحدة، وتجنب شبكة الضيوف.
2. اضغط مرتين على `Run-WESLA-LAN.bat`.
3. اقرأ عنوان IPv4 والمنفذ اللذين يطبعهما الخادم. مثال شكلي: `http://192.168.1.25:3000`؛ استخدم العنوان الحقيقي الظاهر في نافذتك.
4. افتح الرابط على الهاتف. لا تستخدم `localhost` أو `127.0.0.1` أو `0.0.0.0` من الهاتف.
5. إذا منع Windows الاتصال، اسمح بالاتصال على الشبكات الخاصة فقط. لا تفتح المنفذ على الراوتر للإنترنت.

## تشغيل الاختبارات
شغّل `Run-Tests.bat` على Windows، أو نفّذ من جذر المشروع:

```powershell
node --check backend/server.js
node --check scripts/restore-backup.js
node tests/check-frontend.js
node --test tests/integration.test.js tests/regression-v49.test.js tests/restore-backup.test.js
node tests/audit-harness.js
```

## أهم وظائف النسخة
- أدوار منفصلة للمالك والمحل والمورد والسائق والمندوب والمحاسب والمشرف ومقدم الخدمة والمشترك وموظف البرمجيات، مع صلاحيات قابلة للتوسعة.
- بطاقات عضوية قابلة للطباعة وبيانات مستخدمين مصنفة.
- سلة متعددة الموردين، وفاتورة مستقلة لكل مورد، ورسوم شحنة واحدة لكل مجموعة مورد داخل الطلب.
- الحد الائتماني العام وقفل الشراء الآجل بهوية SKU الموحدة فقط.
- دفتر فواتير وبنود ودفعات وتسويات ومطالبات دين وعهدة وخزينة.
- نسخ SQLite متسق عبر `VACUUM INTO` (نسخة أولية بعد دقيقة، ثم كل 6 ساعات، مع الاحتفاظ بآخر 20 نسخة)؛ واستعادة مدققة عبر `Restore-Backup.bat` بعد إيقاف الخادم.
- الإلغاء/الإرجاع على مستوى الصنف، وإعادة مخزون مرة واحدة، وغرامة كـ«مطالبة تسوية» مستقلة لا تخصم تلقائيًا من الدين.
- إشعارات داخل التطبيق وعدّاد غير المقروء. إشعارات Push عندما يكون التطبيق مغلقًا تحتاج HTTPS وإعداد Service Worker/VAPID أو مزود مناسب؛ لا تعدّ هذه الميزة مفعّلة بالكامل في هذه النسخة.

## البيانات والخصوصية
- لا تستخدم بيانات حقيقية، أو جوازات سفر، أو إيصالات، أو سجلات ديون في اختبار LAN.
- مجلدا `uploads/` و`private_uploads/` يُنشآن تلقائيًا عند تشغيل التطبيق. الملفات الخاصة يجب ألّا تُنسخ إلى مستودع عام أو تُشارك كرابط مفتوح.
- قاعدة البيانات تحمل اسم `wesla_v4_8.db` لأغراض توافق الترحيلات التاريخية. لا تحذفها أو تستبدلها إذا كان لديك بيانات تريد الحفاظ عليها.
- خذ نسخة احتياطية واختبر الاستعادة قبل أي تحديث مهم.
- قبل الإنتاج: مراجعة أمنية مستقلة، واختبار صلاحيات/تزامن، وتدقيق محاسبي وقانوني، وتخزين دائم خاص للملفات، وHTTPS، ونسخ احتياطي خارج الجهاز.
