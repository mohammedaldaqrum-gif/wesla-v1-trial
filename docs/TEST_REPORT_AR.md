## تحذيرات وحدود
- نجاح الاختبارات لا يعني اعتمادًا للإنتاج أو اختبار اختراق.
- النسخة الحالية تستخدم SQLite محليًا؛ لا تنشرها كما هي على الإنترنت لإدارة أموال حقيقية.
- إشعارات Push أثناء إغلاق التطبيق تحتاج HTTPS وإعدادًا إضافيًا.
- قبل الإنتاج يجب اختبار التزامن، والنسخ الاحتياطي والاستعادة، والأمان، والامتثال القانوني/المحاسبي.
